A aplicação `apps/accounts` é a interface principal para os usuários gerenciarem suas identidades.

## Funcionalidades

-   **Gerenciamento de Perfil**: Atualização de nome, e-mail e avatar.
-   **Configurações de Segurança**: Alteração de senha, ativação de 2FA.
-   **Gerenciamento de Organização**: Criação e gerenciamento de organizações, convite de membros.

## Integração

É construída com Angular e se comunica com a API via endpoints REST padrão protegidos por tokens OIDC. No Mapa local, executado em `localhost`, o menu de usuário usa `http://localhost:4200`; em hosts não locais, usa a URL pública do Contas.

Durante a edição de um usuário, falhas ao carregar cargos ou entidades finalizam o carregamento e preservam a entidade selecionada para evitar uma tela indefinidamente bloqueada. O detalhe da falha é registrado no console para diagnóstico.

## Estrutura

A aplicação Angular segue uma estrutura baseada em features:

-   `src/app/pages/`: Componentes de roteamento para cada página.
-   `src/app/components/`: Componentes de UI reutilizáveis.
-   `src/app/states/`: Gerenciamento de estado (se aplicável, ex: NgRx ou Signals).
