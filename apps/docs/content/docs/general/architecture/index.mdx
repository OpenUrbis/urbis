A arquitetura do **Urbis** foi projetada para garantir alta performance cartográfica, desacoplamento de responsabilidades, extensibilidade municipal e segurança rigorosa de dados.

---

## 🧭 Pilares Arquiteturais

```mermaid
graph TD
    A[Monorepo Turborepo] --> B[Backend Modular NestJS]
    A --> C[Frontend Especializado por Domínio]
    A --> D[Pacotes Compartilhados Tipados]

    B --> E[(PostgreSQL + Redis + S3)]
    C --> F[Web GIS - React + Deck.gl]
    C --> G[Accounts - Angular 20 OIDC]
    C --> H[Legis - React + Tiptap]
    C --> I[Docs - Next.js Fumadocs]
```
