O Urbis utiliza uma stack tecnológica robusta e moderna, projetada para escalabilidade, segurança de tipos e produtividade do desenvolvedor.

## Backend

-   **[NestJS](https://nestjs.com/)**: Um framework Node.js progressivo para construir aplicações do lado do servidor eficientes, confiáveis e escaláveis.
-   **[TypeScript](https://www.typescriptlang.org/)**: Superset de JavaScript estritamente tipado.
-   **[PostgreSQL](https://www.postgresql.org/)**: Banco de dados relacional primário.
-   **[TypeORM](https://typeorm.io/)**: ORM para interagir com o banco de dados usando classes TypeScript.
-   **[Redis](https://redis.io/)**: Armazenamento de dados em memória para cache e gerenciamento de sessões.
-   **[Passport](http://www.passportjs.org/)**: Middleware de autenticação.
-   **[OIDC Provider](https://github.com/panva/node-oidc-provider)**: Implementação OpenID Connect para gerenciamento seguro de identidade.

## Frontend

-   **[Angular](https://angular.io/)**: Plataforma para construir aplicações web (usado em `apps/accounts`).
-   **[React](https://react.dev/)**: Biblioteca para construir interfaces de usuário (usado em `apps/web`, `apps/site`, `apps/docs`, `packages/ui`).
-   **[Next.js](https://nextjs.org/)**: Framework React para produção (usado em `apps/docs`).
-   **[Vite](https://vitejs.dev/)**: Ferramenta de Frontend de Próxima Geração (usado em `apps/web`, `apps/site`).
-   **[Tailwind CSS](https://tailwindcss.com/)**: Framework CSS utility-first para estilização.

## Monorepo & Ferramentas

-   **[Turborepo](https://turbo.build/)**: Sistema de build de alta performance para monorepos JavaScript/TypeScript.
-   **[pnpm](https://pnpm.io/)**: Gerenciador de pacotes rápido e eficiente em espaço em disco.
-   **[Docker](https://www.docker.com/)**: Plataforma de containerização.
-   **[Jest](https://jestjs.io/)**: Framework de testes.
-   **[ESLint](https://eslint.org/)**, **[Prettier](https://prettier.io/)** & **[Biome](https://biomejs.dev/)**: Linting e formatação de código.
