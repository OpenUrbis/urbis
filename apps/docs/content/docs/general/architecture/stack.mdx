Monorepo Boilerplate utilizes a robust, modern technology stack designed for scalability, type safety, and developer productivity.

## Backend

-   **[NestJS](https://nestjs.com/)**: A progressive Node.js framework for building efficient, reliable and scalable server-side applications.
-   **[TypeScript](https://www.typescriptlang.org/)**: Strictly typed JavaScript superset.
-   **[PostgreSQL](https://www.postgresql.org/)**: Primary relational database.
-   **[TypeORM](https://typeorm.io/)**: ORM for interacting with the database using TypeScript classes.
-   **[Redis](https://redis.io/)**: In-memory data store for caching and session management.
-   **[Passport](http://www.passportjs.org/)**: Authentication middleware.
-   **[OIDC Provider](https://github.com/panva/node-oidc-provider)**: OpenID Connect implementation for secure identity management.

## Frontend

-   **[Angular](https://angular.io/)**: Platform for building web applications (used in `apps/accounts`).
-   **[Angular Material](https://material.angular.io/)**: Material Design components for Angular (M3).
-   **[React](https://react.dev/)**: Library for building user interfaces (used in `apps/docs`, `apps/app`, `packages/ui`).
-   **[Vite](https://vitejs.dev/)**: Next Generation Frontend Tooling (used in `apps/app`).
-   **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework for styling (used in `apps/docs`, `apps/app`).

## Monorepo & Tooling

-   **[Turborepo](https://turbo.build/)**: High-performance build system for JavaScript/TypeScript monorepos.
-   **[pnpm](https://pnpm.io/)**: Fast, disk space efficient package manager.
-   **[Docker](https://www.docker.com/)**: Containerization platform.
-   **[Jest](https://jestjs.io/)**: Testing framework.
-   **[ESLint](https://eslint.org/)**, **[Prettier](https://prettier.io/)** & **[Biome](https://biomejs.dev/)**: Code linting and formatting.
