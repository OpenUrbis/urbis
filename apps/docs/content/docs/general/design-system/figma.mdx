O arquivo do Figma serve como referência direta para design, desenvolvimento e validação.  
Tudo o que foi implementado no código existe previamente no Figma.

## O que o arquivo contém

O arquivo do Figma foi estruturado para servir como referência e base de reutilização para qualquer pessoa que venha a usar a ferramenta no futuro.

### Estrutura geral

* **Fundamentos**

  * Aplicação em layouts
  * Tipografia
  * Cores
  * Ícones
  * Estilos de efeito

* **Componentes**

  * Componentes existentes
  * Estados e variantes funcionais

---

## Como usar o Figma

O uso do Figma é simples e direto:

1. Acesse o arquivo oficial do projeto
2. Duplique o arquivo para o seu workspace
3. Utilize os estilos e componentes existentes como base
