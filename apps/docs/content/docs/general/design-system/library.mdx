A biblioteca de componentes do Urbis é baseada no **shadcn/ui**.
Ela é utilizada como fundação técnica para a construção da interface, garantindo velocidade de desenvolvimento, consistência e acessibilidade desde a base.

## Por que shadcn/ui

A escolha do shadcn/ui atende a objetivos práticos do projeto.

### Acessibilidade e agilidade

* Componentes já preparados para navegação por teclado
* Estados de foco e interação consistentes
* Boas práticas de acessibilidade incorporadas
* Redução de retrabalho em requisitos não funcionais

### Facilidade de implementação

* Componentes simples de importar e adaptar
* Estrutura clara e previsível
* Integração direta com Tailwind CSS
* Código legível e fácil de manter

### Escalabilidade e ampliação futura

* Ampla variedade de componentes já disponíveis
* Base consistente para criação de novos componentes
* Possibilidade de customização sem quebra de padrão
* Evolução contínua do design system

## Uso no projeto

Os componentes foram utilizados como base e adaptados para as necessidades e personalizações específicas da Urbis.
