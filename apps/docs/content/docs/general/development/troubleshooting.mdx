Problemas comuns que os desenvolvedores podem encontrar e suas soluções.

## Conexão com Banco de Dados Recusada

**Erro**: `ECONNREFUSED 127.0.0.1:5432`

**Solução**:
1.  Certifique-se de que o Docker está rodando.
2.  Verifique se o container do banco de dados está no ar: `docker ps`.
3.  Se executar `pnpm composer:up` falhar com "port already in use", pare outras instâncias do Postgres rodando na sua máquina.

## Permissões do Docker (Linux)

**Erro**: `permission denied while trying to connect to the Docker daemon socket`

**Solução**:
Adicione seu usuário ao grupo docker:
```bash
sudo usermod -aG docker $USER
newgrp docker
```

## Problemas de Cache do Turbo Build

**Problema**: Alterações não estão sendo refletidas no build.

**Solução**:
Force um rebuild ignorando o cache:
```bash
pnpm build --force
```

## Problemas de Redirecionamento OIDC

**Problema**: "Invalid redirect_uri" ao tentar fazer login.

**Solução**:
Certifique-se de que a URL do seu frontend corresponde ao que está na lista de permissões na configuração do Provedor OIDC (`apps/api/src/auth/oidc/oidc.config.ts`).
