# Códigos de Erro - Urbis Map

Este documento lista todos os códigos de erro utilizados na aplicação web do Urbis Map para o sistema de carregamento inicial.

## Estrutura do Código

Os códigos seguem o formato `X000123DS` onde:
- `X`: Módulo (M=Map, S=Search, R=Restore, G=General)
- `000123`: Sequencial
- `DS`: Severidade (DS=Disruptive, WR=Warning, IF=Info)

## Lista de Erros

### Carregamento de Mapa (M)

| Código | Mensagem | Descrição | Solução Sugerida |
|--------|----------|-----------|------------------|
| `M001001DS` | Erro ao carregar configurações do mapa | Falha ao obter as camadas e configurações iniciais da API (`GET /maps/config/map`). Causas possíveis: sem internet, API fora do ar, bloqueio de CORS ou **certificado TLS da API expirado/inválido**. | Verificar conexão com internet. Verificar se a API de mapas está online. Tentar recarregar a página. Para a equipe técnica: veja a seção [Diagnóstico do `M001001DS`](#diagnóstico-do-m001001ds) abaixo. |
| `M001002DS` | Timeout no carregamento do mapa | O carregamento das camadas excedeu o tempo limite. | A conexão pode estar lenta. Tentar recarregar a página. |

#### Diagnóstico do `M001001DS`

O mesmo código aparece para qualquer falha na chamada de configuração do mapa. Para descobrir a causa:

1. Abra `https://api.mapa.urbis.prefeitura.sp.gov.br/maps/config/map` no navegador.
   - **Aviso de segurança / "Sua conexão não é particular"** (`NET::ERR_CERT_DATE_INVALID`): o certificado TLS da API expirou. Veja [Certificados TLS](/docs/general/infrastructure/deploy#certificados-tls-cert-manager--lets-encrypt).
   - **Erro 5xx ou sem resposta**: a API (`urbis-map-api`) está indisponível; verifique os pods no cluster `Urbis`, namespace `urbis-map`.
   - **JSON com as camadas**: a API está saudável; o problema é de rede local, CORS ou do navegador do usuário.
2. Para verificar a validade do certificado: `echo | openssl s_client -connect api.mapa.urbis.prefeitura.sp.gov.br:443 -servername api.mapa.urbis.prefeitura.sp.gov.br 2>/dev/null | openssl x509 -noout -enddate`.

> **Ocorrência registrada:** em 06/11/2026 o certificado da API expirou porque a renovação automática estava travada (solver HTTP-01 ignorado pelo ingress-nginx). Detalhes e correção em [Certificados TLS](/docs/general/infrastructure/deploy#certificados-tls-cert-manager--lets-encrypt).

### Configurações de Pesquisa (S)

| Código | Mensagem | Descrição | Solução Sugerida |
|--------|----------|-----------|------------------|
| `S001001WR` | Erro ao carregar configurações de busca | Falha ao obter as opções de pesquisa disponíveis. | A busca pode funcionar parcialmente. Tentar recarregar a página. |

### Restauração de Sessão (R)

| Código | Mensagem | Descrição | Solução Sugerida |
|--------|----------|-----------|------------------|
| `R001001WR` | Erro ao restaurar sessão compartilhada | O link de compartilhamento é inválido ou expirou. | Verificar se o link está correto. O mapa será carregado no estado padrão. |
| `R001002WR` | Dados de sessão corrompidos | Os dados salvos localmente ou no link estão inválidos. | Limpar dados de navegação ou ignorar e usar o estado padrão. |
