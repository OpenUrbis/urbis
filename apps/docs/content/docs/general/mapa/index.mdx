O módulo de mapas do **Urbis** é responsável pela renderização geoespacial de alta performance, cruzamento de dados territoriais, ferramentas de medição e análise urbanística.

---

## 🗺️ Tecnologias Principais

- **MapLibre GL**: Motor cartográfico vetorial para renderização de mapas base, estilos e navegação suave.
- **Deck.gl 9**: Renderização de camadas WebGL com alta taxa de quadros (FPS) para dezenas de milhares de geometrias, polígonos e visualização 3D.
- **Endereço Digital / Plus Code**: Localização métrica (1m²) de lotes e pontos de interesse sem dependência de CEP.
- **GeoServer WMS/WFS**: Integração nativa com servidores padrão OGC para consumo de geometrias vetoriais e tiles raster.
