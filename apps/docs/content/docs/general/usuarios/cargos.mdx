Neste documento, você aprenderá como realizar o cadastro ou edição dos cargos existentes no sistema, desde que possua as devidas permissões.

## Acessando os Cargos

Para iniciar, acesse o menu **Cargos**. Nesta tela, você visualizará a lista de cargos já cadastrados no sistema.

Se você tiver permissão e o cargo não for sistêmico, poderá editá-lo clicando no ícone de lápis.

Para criar um novo cargo, clique no botão **Criar**.

![Lista de cargos](/gerenciar-cargos/listar-cargos.png)

## Criando ou Editando um Cargo

No modal que aparece ao criar ou editar um cargo, você pode configurar as seguintes informações:

- **Nome**: O nome do cargo.
- **Descrição**: Uma breve descrição da função do cargo.
- **Padrão**: Definir se este cargo é o padrão.
- **Permissões**: Adicionar as permissões que deseja atribuir a este cargo.

### Escopos de Permissão

Ao adicionar uma permissão, é necessário definir o escopo de acesso. As opções são:

- **Global**: Tem acesso a todos os dados de todas as organizações, desde a organização pai.
- **Qualquer**: Tem acesso a todos os dados das organizações próprias e filhas.
- **Proprietário**: Tem acesso a todos os dados somente da própria organização.
