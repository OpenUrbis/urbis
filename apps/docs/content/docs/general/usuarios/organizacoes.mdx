Para realizar a gestão das organizações, o usuário deve possuir as permissões necessárias.

## Acessando as Organizações

Acesse a tela de **Organizações** para visualizar a lista de organizações cadastradas.

Nesta tela, é possível:
- **Alterar** uma organização existente clicando no botão com ícone de lápis.
- **Criar** uma nova organização clicando no botão **Criar**.

![Lista de organizações](/Gerenciar%20orgs/Listar%20orgs.png)

## Criando uma Organização

Para criar uma nova organização, insira um **nome** e uma **descrição** e clique em **Salvar**.

![Criar organização](/Gerenciar%20orgs/Criar%20org.png)

## Editando uma Organização

Na tela de edição, você pode alterar o nome e a descrição da organização. Além disso, é possível visualizar quais usuários estão associados a esta organização.

![Editar organização](/Gerenciar%20orgs/Edit%20org.png)
