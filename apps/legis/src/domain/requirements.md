#### **Filiação**

#### Antes de salvar o Original normativo, o sistema deve exibir uma tela com a sequência dos Tipos de elemento dos Elementos normativos + Índice (ex.: “Capítulo 2”, “Artigo 3º”, “Inciso I”), indicando com indentações e linhas de ligação as relações de filiação. Também deve permitir que o usuário facilmente faça seleção de elementos e preencha ou edite sua paternidade, SEM ALTERAR a ordem dos elementos - que não se altera com a filiação (observação: com isso, ligações de filiação mal-formadas podem cruzar outros elementos - mas isso é proposital, para que o usuário identifique e corrija).Referência visual para a ferramenta: [Image removed]

#### **Visualização de vínculos**

Ao visualizar um Original normativo, deve haver um modo de visualização que permita visualizar os Elementos normativos que possuam vínculo com Coletâneas temáticas com um fundo de contraste (conforme _design system_), e saber com quais (sugestão: painel à esquerda, com modais).

### **Descrição completa**

Como se disse, as páginas das Coletâneas temáticas possuirão conteúdo normativo e não normativo. Os conteúdos normativos serão dinâmicos e gerados a partir de seleções de Elementos normativos de um ou mais Originais normativos, formando sequências, intercaladas ou não por outros tipos de conteúdo.


#### **Conteúdos normativos - Sequências**

Tendo como premissa o cadastro de todos os Elementos normativos e situações especiais, e a partir de uma sequência de IDs de Elementos normativos de um mesmo Original Normativo, o sistema deverá trazer na página da Coletânea temática a estrutura superior dos Elementos normativos até a norma, conforme especificado na seção _Originais normativos - Situações especiais >> Ferramentas básicas >> Dispositivo com estrutura completa_, com as considerações a seguir.


##### **Identificação da norma com ementa e preâmbulo**

Quanto à identificação da norma (Original normativo) de cada sequência, ela deve ser complementada com o Nome do Original normativo ou, se não houver, a sua última Ementa EM VIGOR, entre aspas e parêntesis.

Exemplo: 

Dados do Original normativo:

2. Tipo normativo: “Lei”

3. Número da norma: “10.406”

4. Data do ato: “10.01.2002”

5. Data de publicação: “11.01.2002”

6. Autoridade: _\<ID da Autoridade “BRASIL”>_

7. Ementa: “Institui o Código Civil.”

8. Nome: “Código Civil”

9. Preâmbulo: “O PRESIDENTE DA REPÚBLICA Faço saber que o Congresso Nacional decreta e eu sanciono a seguinte Lei:”

Resultado:

BRASIL. **Lei nº 10.406/2002** (“Código Civil”)

Também deve ser possível exibir o preâmbulo do Original normativo de cada sequência, integral ou em trechos.

Atenção: cada sequência de Elementos normativos possui autonomia, por isso, cada sequência pode possuir diferentes trechos do Preâmbulo.


##### **Elementos normativos**

Quanto aos Elementos normativos, deve-se pressupor para cada sequência que eles estão na mesma ordem em que ocorrem no Original normativo respectivo. Atenção: cada sequência de Elementos normativos possui autonomia, por isso, na mesma página, o mesmo Elemento normativo pode ocorrer em diversas sequências.

Para cada sequência, devem ser trazidos conforme a especificação em Originais normativos - Situações especiais >> Ferramentas básicas >> Dispositivo com estrutura completa, e exibidos considerando as Situações especiais.

Considerando a multiplicidade de Elementos normativos repassados à função, o retorno com os Elementos normativos superiores até o nível de artigo, não deve possuir Elementos normativos pai em duplicidade. No exemplo a seguir, são de interesse os Elementos normativos com texto em roxo:

#### **Conteúdos não normativos**

Os conteúdos não normativos devem incluir: (1) texto formatado conforme as opções do _design system_, com opções de itálico, negrito, sublinhado, sobretexto, subtexto, alinhamento (esquerdo, central, direito ou justificado), cores e variações de tamanho (maior e menor que o normal); (2) cabeçalhos para hierarquização dos conteúdos, com 4 níveis e duas classes possíveis (estática e dinâmica - cf. Modo consolidado, adiante); (3) tabelas, com formatação conformes ao _design system_; (4) mapas clicáveis; (5) imagens, com configurações de tamanho (largura x altura); (6) vídeos, com configurações de tamanho (largura x altura); e (7) links (associados a textos, áreas dos mapas clicáveis ou imagens para arquivos internos, conteúdos internos ou URLs externas, com configuração de _target_).

Todos os elementos não normativos devem ter recuo esquerdo configurável.


#### **Modo consolidado**

O sistema deve identificar as partes com normas inativas, para possibilitar sua não exibição no Modo consolidado (a exibição normal é o Modo completo). Isso é feito a partir dos Elementos normativos, que são integralmente inativos quando:

1. a última Situação especial EM VIGOR for:

   1. “Revogação”, “Anulação” ou “Cassação”

   2. “Veto”, “Perda definitiva de vigor/eficácia” ou “Suspensão de vigor/eficácia” (quando abarcarem o Texto integral)

2. se tratar de versão anterior (tachada) em Novas redações

3. se tratar de Elemento normativo original com vigência finalizada (tachado)

Nos casos acima, são marcados como inativos os _Elementos normativos inteiros_ (incluindo chave e Texto) e _eventual separação “\[...]” da linha acima_.

Se, em uma _sequência_ de Elementos normativos, todos forem integralmente inativos, a identificação da norma (Original normativo) também deve ser marcada como inativa. Caso contrário, se o primeiro Elemento normativo ativo possuir _separação “\[...]” na linha acima_, esta também deverá ser marcada como inativa.

Caso haja _cabeçalhos com classe dinâmica_ (cf. seção Conteúdos não normativos, acima) organizando as sequências de Elementos normativos, e todas as sequências de Elementos normativos imediatamente dentro dele (ou seja, até o próximo cabeçalho) e/ou de cabeçalhos abaixo dele (níveis inferiores) forem inativos, ele também deverá ser marcado como inativo. Se um cabeçalho com classe dinâmica for inativo, todo conteúdo não normativo imediatamente dentro dele (ou seja, até o próximo cabeçalho) também devem ser marcado como inativo.

Além dos elementos integralmente inativos, são _parcialmente_ inativos:

4. os trechos de Texto substituídos por “(VETADO)”

5. os trechos de Texto tachados por “Perda definitiva de vigor/eficácia” ou “Suspensão de vigor/eficácia”

6. as versões anteriores das chaves (tachadas) nas Renumerações

Todos os cabeçalhos, identificações de norma, Elementos normativos e partes _marcadas como inativas_ devem ser _invisíveis no Modo consolidado_. 

Caso um Elemento normativo ativo _imediatamente seguinte a um Elemento normativo integralmente inativo, exceto o primeiro, não possuir separação “\[...]” na linha acima, uma separação “\[...]” deverá ser acrescentada na linha acima._

No caso de apenas _partes inativas_, devem ser inseridas em seu lugar _separações “\[...]” em linha_.

Além dos conteúdos invisíveis, também devem ser invisíveis, no Modo consolidado, todos os modais que _não sejam relativos à Vigência não iniciada_.

Mesmo que os demais modais não sejam exibidos, as formatações do Elemento normativo (como as cores azul, laranja e o sublinhado) devem ser mantidas.


# **Visualização e navegação**

Para o usuário final, devem estar disponíveis as páginas das Coletâneas temáticas em um componente próprio do Urbis, o Legis. A página de entrada deve possuir o seguinte conteúdo:

O Legis é um componente do Urbis voltado à compreensão e utilização de informações normativas (ou seja, sobre leis e similares) relacionadas aos seus conteúdos, em observância às diretrizes para a Linguagem Simples.

Por aqui, podem ser navegadas as suas páginas, categorizadas de acordo com seu foco:

|                          |                                                                                   |
| ------------------------ | --------------------------------------------------------------------------------- |
| **Categoria**            | **Foco**                                                                          |
| **Exigências**           | deveres e direitos _(o que eu devo fazer)_                                        |
| **Competências**         | poderes e deveres dos órgãos ou instituições públicos _(quem devo procurar)_      |
| **Definições**           | entender um conceito técnico-jurídico, sistematicamente _(o que significa isso)_  |
| **Fontes de Informação** | Bases de dados previstas ou implementadas _(onde eu posso pesquisar informações)_ |

A partir daqui, é possível navegar pela ferramenta de Pesquisa (ver manual na seção de Ajuda, no canto superior direito) e depois simplesmente clicando nos links entre uma página e outra (onde?).

Cada página possui um resumo e um conteúdo completo, que pode ser exibido no modo completo ou consolidado (apenas as normas atuais) (onde?).

Os conteúdos do Legis são orientativas e não substituem as publicações oficiais. Para maiores informações, clique [aqui](https://urbis.prefeitura.sp.gov.br/info-urbis).
