# Urbis Site (`@open-urbis/map-site`)

Portal institucional e público da plataforma Urbis, desenvolvido com **React 18**, **Vite** e **Vite React SSG** (Geração de Site Estático).

---

## 🚀 Execução em Desenvolvimento

```bash
pnpm --filter @open-urbis/map-site dev
```

A aplicação estará acessível em: `http://localhost:5174`

---

## 🏗️ Build de Produção e SSG

```bash
pnpm --filter @open-urbis/map-site build
```

---

## 🖼️ Otimização de Imagens

```bash
# Otimizar imagens do site
pnpm --filter @open-urbis/map-site images:optimize

# Verificar integridade das imagens
pnpm --filter @open-urbis/map-site images:check
```
