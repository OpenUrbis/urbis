Licença de Banco de Dados Aberto (ODbL)

Preâmbulo

A Licença de Banco de Dados Aberto (ODbL) é um contrato de licença destinado a permitir que os usuários compartilhem, modifiquem e utilizem livremente este Banco de Dados, mantendo essa mesma liberdade para outros. Muitos bancos de dados são protegidos por direitos de propriedade intelectual e, portanto, este documento licencia esses direitos. Algumas jurisdições, principalmente na União Europeia, possuem direitos específicos que abrangem bancos de dados, e por isso a ODbL também aborda esses direitos. Por fim, a ODbL é também um acordo contratual para que os usuários deste Banco de Dados ajam de determinadas maneiras em troca do acesso a este Banco de Dados.
Os bancos de dados podem conter uma ampla variedade de tipos de conteúdo (imagens, material audiovisual e sons, todos no mesmo banco de dados, por exemplo) e, portanto, a ODbL rege apenas os direitos sobre o Banco de Dados, e não o conteúdo do Banco de Dados individualmente. Os licenciantes devem usar a ODbL juntamente com outra licença para o conteúdo, caso este tenha um único conjunto de direitos que abranja uniformemente todo o conteúdo. Se o conteúdo tiver múltiplos conjuntos de direitos diferentes, os licenciantes devem descrever quais direitos regem quais conteúdos no registro individual ou de alguma outra forma que esclareça quais direitos se aplicam.
Às vezes, o conteúdo de um banco de dados, ou o próprio banco de dados, pode ser coberto por outros direitos não abordados aqui (como contratos privados, marca registrada sobre o nome ou direitos de privacidade/direitos de proteção de dados sobre as informações contidas no conteúdo); portanto, recomenda-se que você consulte outros documentos ou esclareça outros direitos antes de realizar atividades não cobertas por esta Licença.
