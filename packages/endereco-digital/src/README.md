# Endereço Digital

Este diretório contém a implementação-fonte da solução **Endereço Digital**.

## Propriedade intelectual e autoria

A solução **Endereço Digital** é propriedade intelectual da **Prefeitura de São Paulo**, com autoria da **CODATA** e **Atlas**.
